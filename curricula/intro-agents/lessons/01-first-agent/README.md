# Lesson 1 — Your first agent task

Ask Claude to create a file called `hello.txt` containing today's date.

Then ask it to explain, line by line, what it just did.

**Goal:** see that the agent acts on your filesystem, and that you can
always ask it to justify what it did.

> Your files belong in `~/work`. The `~/lessons` folder is the course
> material — read it, don't write to it.
